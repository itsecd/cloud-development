# Лабораторная работа №1  
## «Кэширование» — Современные технологии разработки программного обеспечения

## Описание работы

В рамках данной лабораторной работы реализована микросервисная система генерации контрактов с использованием современных технологий разработки на платформе .NET 8.

Основной целью работы является изучение:
- межсервисного взаимодействия,
- распределённого кэширования,
- структурного логирования,
- оркестрации приложений при помощи .NET Aspire.

---

# Реализованный функционал

В ходе выполнения лабораторной работы были реализованы:

- сервис генерации контрактов на основе библиотеки Bogus;
- кэширование данных при помощи Redis и IDistributedCache;
- структурное логирование через ILogger;
- клиентское приложение на Blazor WebAssembly;
- оркестрация сервисов при помощи .NET Aspire;
- Swagger документация API;
- генерация случайных данных о проектах разработки ПО.

---

# Созданные проекты

## 1. CloudDevelopment.AppHost
Проект оркестрации Aspire.

Отвечает за:
- запуск всех сервисов,
- управление зависимостями,
- подключение Redis,
- отображение Dashboard.

---

## 2. GenerationService
Основной backend-сервис генерации контрактов.

Реализует:
- REST API;
- генерацию контрактов;
- работу с Redis;
- кэширование запросов;
- логирование.

---

## 3. Client.Wasm
Клиентское приложение на Blazor WebAssembly.

Позволяет:
- отправлять запросы к API;
- получать данные контрактов;
- отображать информацию пользователю.

---

## 4. CloudDevelopment.ServiceDefaults
Общий проект с настройками сервисов Aspire.

Содержит:
- конфигурацию OpenTelemetry;
- общие настройки сервисов;
- конфигурацию логирования и мониторинга.
