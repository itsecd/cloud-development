## 🧪 Лабораторная работа №3 — «Интеграционное тестирование»

### Реализовано:
- **LocalStack** (S3 + SNS + SQS)
- **FileService** — сохраняет контракты в объектное хранилище
- **Межсервисная коммуникация** через Amazon SNS → SQS
- **Интеграционные тесты** (Aspire.Hosting.Testing + xUnit)

### Архитектура
- Генератор → Redis (кэш) → SNS → SQS → FileService → S3

### Тесты проверяют:
- Генерацию через API Gateway
- Работу кэширования
- Сохранение контракта в S3
- Возможность получения файла по имени
